Druida 2 do Círculo da Lua / Paladino 1, gnomo da floresta. Sabedoria 16.

## Uso

A interface acompanha PV, espaços de magia, Forma Selvagem, concentração e anotações. Os dados da sessão ficam no navegador de cada dispositivo. Use exportar/importar no Caderno para transferir ou guardar sua sessão. O repositório não armazena automaticamente suas anotações.

Também é possível baixar o pacote ZIP, extrair e abrir luci-ui.html sem conexão.

## Documentação

Os arquivos DOCX e Markdown incluem ficha, guia completo com páginas impressas/PDF, consulta rápida de uma página e história. luci.png é a arte final. Consulte LEIA-ME.md para os valores e pendências da ficha.

Regras exclusivamente do Livro do Jogador fornecido, edição original de 2014. O PDF do livro e as fotografias de referência não são redistribuídos neste repositório. A arte e a aparência não concedem poderes extras.

## Publicação

GitHub Pages publica a branch main, pasta raiz. index.html é a entrada pública; luci-ui.html é a versão original para uso local. Após atualizar main, acompanhe o deployment no GitHub.
